# লুডু আড্ডা কন্ট্রোল সার্ভার

লোকাল ডেভেলপমেন্টের জন্য এটি গেম-অপারেশন API ভিত্তি। লাইভ ম্যাচ দেখা, ম্যাচ স্থগিত/পুনরায় চালু/বাতিল, রিপোর্ট সমাধান, নোটিশ প্রকাশ ও অডিট লগের ডেমো আছে। সব ডেটা মেমরিতে থাকে এবং সার্ভার বন্ধ হলে মুছে যায়।

এতে পেমেন্ট, বেট, ওয়ালেট, রিচার্জ, বিকাশ, নগদ উত্তোলন বা payout নেই। সেসব চালু করার আগে অনুমোদিত ব্যবসায়িক কাঠামো, আইনি পর্যালোচনা, নিরাপত্তা নকশা এবং বিকাশের নিজস্ব API অনুমোদন প্রয়োজন।

## চালানো

```powershell
cd server
Copy-Item .env.example .env
npm install
$env:ADMIN_KEY = "নিজের-লম্বা-গোপন-কী"
npm start
```

পরীক্ষার জন্য `X-Admin-Key` হেডারে একই কী পাঠাও।

## প্রোডাকশনের আগে

- PostgreSQL বা সমমানের ডেটাবেস
- কর্মীভিত্তিক লগইন ও role-based access
- HTTPS, secret manager এবং audit retention
- সার্ভার-নিয়ন্ত্রিত ডাইস/চাল ও রিয়েল-টাইম WebSocket ম্যাচ সার্ভার
- চ্যাট moderation queue ও rate limiting
